# Ritual

[Amn](../runes.md#amn-rune) + [Shael](../runes.md#shael-rune) + [Ohm](../runes.md#ohm-rune) in a 3-socket knife.

|  |  |

| Rune order | Amn Rune, Shael Rune, Ohm Rune |
| Required level | 57 (the highest rune's) |

## Properties

- 13% Chance to cast level 1 Sigil: Death when struck
- +40% Increased Attack Speed
- +(250-320)% Enhanced Damage
- (200-260)% Bonus to Attack Rating
- +(150-250)% Damage to Demons
- 7% Life stolen per hit
- Slain Monsters Rest in Peace
- +(3-5) Life after each Kill

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
