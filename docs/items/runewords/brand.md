# Brand

[Jah](../runes.md#jah-rune) + [Lo](../runes.md#lo-rune) + [Mal](../runes.md#mal-rune) + [Gul](../runes.md#gul-rune) in a 4-socket missile weapon.

|  |  |
| --- | --- |
| Sockets | 4 |
| Rune order | Jah Rune, Lo Rune, Mal Rune, Gul Rune |
| Required level | 65 (the highest rune's) |
| Fits | Missile Weapon |

## Properties

- 100% Chance to cast level 18 Bone Spear on striking
- 35% Chance to cast level 14 Amplify Damage when struck
- Fires Explosive Arrows or Bolts
- +(260-340)% Enhanced Damage
- Ignore Target's Defense
- 20% Bonus to Attack Rating
- +(280-330)% Damage to Demons
- +20% Deadly Strike
- Prevent Monster Heal
- Knockback

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 4 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
