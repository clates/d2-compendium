# Automagic (class item) affixes

Some bases always carry one of these on top of their other affixes: class-specific items get their skill line here (the "auto prefix" column of the base tables names the group). Each group below is one affix group: an item can't carry two affixes from the same group. Affixes marked † exist only for Reign of the Warlock characters; "Rare: no" affixes only appear on magic items. Table rows with frequency 0 (Classic-era duplicates that never roll) are left out.

Columns: **Level** is the affix's level (it can roll when the item's affix level is at least this), **Max** the level above which it no longer rolls, **Req** the required level it adds, **Freq** its weight within the candidates. See [Item generation](../../mechanics/item-generation.md) for how affix level comes from item level.
