# King's Grace

[Amn](../runes.md#amn-rune) + [Ral](../runes.md#ral-rune) + [Thul](../runes.md#thul-rune) in a 3-socket sword, scepter.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Amn Rune, Ral Rune, Thul Rune |
| Required level | 25 (the highest rune's) |
| Fits | Sword, Scepter |

## Properties

- +100% Enhanced Damage
- +150 to Attack Rating
- +100% Damage to Demons
- +100 to Attack Rating against Demons
- +50% Damage to Undead
- +100 to Attack Rating against Undead
- Adds 5-30 fire damage
- Adds 3-14 cold damage
- 7% Life stolen per hit

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
