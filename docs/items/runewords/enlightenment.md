# Enlightenment

[Pul](../runes.md#pul-rune) + [Ral](../runes.md#ral-rune) + [Sol](../runes.md#sol-rune) in a 3-socket armor.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Pul Rune, Ral Rune, Sol Rune |
| Required level | 45 (the highest rune's) |
| Fits | Armor |

## Properties

- 5% Chance to cast level 15 Fire Ball on striking
- 5% Chance to cast level 15 Blaze when struck
- +2 to Sorceress Skill Levels
- +1 to Warmth
- +30% Enhanced Defense
- Fire Resist +30%
- Damage Reduced by 7

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
