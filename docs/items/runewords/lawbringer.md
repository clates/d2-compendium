# Lawbringer

[Amn](../runes.md#amn-rune) + [Lem](../runes.md#lem-rune) + [Ko](../runes.md#ko-rune) in a 3-socket sword, hammer, scepter.

|  |  |

| Rune order | Amn Rune, Lem Rune, Ko Rune |
| Required level | 43 (the highest rune's) |
| Fits | Sword, Hammer, Scepter |

## Properties

- 20% Chance to cast level 15 Decrepify on striking
- Level (16-18) Sanctuary Aura When Equipped
- -50% Target Defense
- Adds 150-210 fire damage
- Adds 130-180 cold damage
- 7% Life stolen per hit
- Slain Monsters Rest in Peace
- +(200-250) Defense vs. Missile
- +10 to Dexterity
- 75% Extra Gold from Monsters

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
