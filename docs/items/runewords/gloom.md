# Gloom

[Fal](../runes.md#fal-rune) + [Um](../runes.md#um-rune) + [Pul](../runes.md#pul-rune) in a 3-socket armor.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Fal Rune, Um Rune, Pul Rune |
| Required level | 47 (the highest rune's) |
| Fits | Armor |

## Properties

- 15% Chance to cast level 3 Dim Vision when struck
- +10% Faster Hit Recovery
- +(200-260)% Enhanced Defense
- +10 to Strength
- All Resistances +45
- Half Freeze Duration
- +5% Damage Taken Goes To Mana
- -3 to Light Radius

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
