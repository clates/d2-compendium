# Principle

[Ral](../runes.md#ral-rune) + [Gul](../runes.md#gul-rune) + [Eld](../runes.md#eld-rune) in a 3-socket armor.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Ral Rune, Gul Rune, Eld Rune |
| Required level | 53 (the highest rune's) |
| Fits | Armor |

## Properties

- 100% Chance to cast level 5 Holy Bolt on striking
- +2 to Paladin Skill Levels
- +50% Damage to Undead
- +(100-150) to Life
- 15% Slower Stamina Drain
- +5% to Maximum Poison Resist
- Fire Resist +30%

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
