# Delirium

[Lem](../runes.md#lem-rune) + [Ist](../runes.md#ist-rune) + [Io](../runes.md#io-rune) in a 3-socket helm.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Lem Rune, Ist Rune, Io Rune |
| Required level | 51 (the highest rune's) |
| Fits | Helm |

## Properties

- 11% Chance to cast level 18 Confuse on striking
- 1% Chance to cast level 50 Delirium when struck
- 6% Chance to cast level 14 Mind Blast when struck
- 14% Chance to cast level 13 Terror when struck
- +2 to All Skills
- +261 Defense
- +10 to Vitality
- 50% Extra Gold from Monsters
- 25% Better Chance of Getting Magic Items
- Level 17 Attract (60/60 Charges)

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
