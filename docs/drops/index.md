# Drops

When a monster dies, the game rolls on its treasure class (shown on each monster's page). A treasure class is a weighted list: each **pick** chooses one entry by weight, and an entry is either an item or another treasure class to roll on in turn. **NoDrop** is the weight of dropping nothing; more players in the game shrink it. Once an item base is chosen, its quality (unique, set, rare, magic...) is rolled using the quality factors along the way, the item level and magic find. See [Item generation](../mechanics/item-generation.md).

The "per pick" column is the chance of each entry on one pick with one player and no NoDrop reduction. It doesn't follow the chain into sub-classes.
