# Magic affixes

- [Magic prefixes](prefixes.md)
- [Magic suffixes](suffixes.md)
- [Automagic (class item) affixes](automagic.md)

Rare items draw their names from separate name tables and take their modifiers from the same prefix and suffix lists (affixes marked "Rare: no" excepted). Crafted items get fixed modifiers from their [cube recipe](../cube-recipes.md) plus random affixes.
