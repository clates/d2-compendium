# Splendor

|  |  |
| --- | --- |
| Sockets | 2 |
| Rune order | Eth Rune, Lum Rune |

## Properties

- +1 to All Skills
- +10% Faster Cast Rate
- +20% Faster Block Rate
- +(60-100)% Enhanced Defense
- +10 to Energy
- Regenerate Mana 15%
- 50% Extra Gold from Monsters
- 20% Better Chance of Getting Magic Items
- +3 to Light Radius

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 2 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
