# Holy Thunder

[Eth](../runes.md#eth-rune) + [Ral](../runes.md#ral-rune) + [Ort](../runes.md#ort-rune) + [Tal](../runes.md#tal-rune) in a 4-socket scepter.

|  |  |
| --- | --- |
| Sockets | 4 |
| Rune order | Eth Rune, Ral Rune, Ort Rune, Tal Rune |
| Required level | 21 (the highest rune's) |
| Fits | Scepter |

## Properties

- +60% Enhanced Damage
- +10 to Maximum Damage
- -25% Target Defense
- Adds 5-30 fire damage
- Adds 21-110 lightning damage
- +75 poison damage over 5 seconds
- +3 to Holy Shock (Paladin Only)
- +5% to Maximum Lightning Resist
- Lightning Resist +60%
- Level 7 Chain Lightning (60/60 Charges)

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 4 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
