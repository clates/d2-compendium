# Bone

[Sol](../runes.md#sol-rune) + [Um](../runes.md#um-rune) + [Um](../runes.md#um-rune) in a 3-socket armor.

|  |  |
| --- | --- |

| Rune order | Sol Rune, Um Rune, Um Rune |
| Required level | 47 (the highest rune's) |

## Properties

- 15% Chance to cast level 10 Bone Spear on striking
- 15% Chance to cast level 10 Bone Armor when struck
- +2 to Necromancer Skill Levels
- +(100-150) to Mana
- All Resistances +30
- Damage Reduced by 7

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
