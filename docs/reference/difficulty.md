# Difficulty levels

What changes between Normal, Nightmare and Hell. Values are the game's; the labels are this codex's reading of the column names. See [Difficulty](../mechanics/difficulty.md) for what each one does.

|  | Normal | Nightmare | Hell |
| --- | ---: | ---: | ---: |
