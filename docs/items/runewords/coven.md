# Coven

[Ist](../runes.md#ist-rune) + [Ral](../runes.md#ral-rune) + [Io](../runes.md#io-rune) in a 3-socket helm.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Ist Rune, Ral Rune, Io Rune |
| Required level | 51 (the highest rune's) |
| Fits | Helm |

## Properties

- 5% Chance to cast level 10 Sigil: Lethargy when struck
- +1 to All Skills
- +20% Faster Cast Rate
- +(30-50)% Enhanced Defense
- +10 to Vitality
- Fire Resist +30%
- +(1-5) Life after each Kill
- (26-40)% Better Chance of Getting Magic Items

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
