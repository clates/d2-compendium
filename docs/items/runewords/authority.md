# Authority

[Hel](../runes.md#hel-rune) + [Shael](../runes.md#shael-rune) + [Ral](../runes.md#ral-rune) in a 3-socket armor.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Hel Rune, Shael Rune, Ral Rune |
| Required level | 29 (the highest rune's) |
| Fits | Armor |

## Properties

- 10% Chance to cast level 15 Miasma Chain on striking
- 2% Chance to cast level 10 Psychic Ward when struck
- +2 to Warlock Skills
- +20% Faster Hit Recovery
- +(40-60)% Enhanced Damage
- Fire Resist +30%
- Requirements -15%

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
