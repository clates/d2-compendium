# Equipment treasure classes

The game builds these itself, not from a table: `armoN` holds every armor base whose quality level is N-2 to N, `weapN` every weapon, `bowN` missile weapons and `meleN` melee weapons, each weighted by the base's rarity. Monster treasure classes point at them.
