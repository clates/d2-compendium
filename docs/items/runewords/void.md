# Void

[Thul](../runes.md#thul-rune) + [Zod](../runes.md#zod-rune) + [Ist](../runes.md#ist-rune) in a 3-socket knife.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Thul Rune, Zod Rune, Ist Rune |
| Required level | 69 (the highest rune's) |
| Fits | Knife |

## Properties

- Indestructible
- +2 to All Skills
- +40% Faster Cast Rate
- Adds 3-14 cold damage
- +(10-15)% to Magic Skill Damage
- +(1-3) to Abyss
- +(8-12) to all Attributes
- 30% Better Chance of Getting Magic Items
- Level 4 Decrepify (35/35 Charges)

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
