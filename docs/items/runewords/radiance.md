# Radiance

[Nef](../runes.md#nef-rune) + [Sol](../runes.md#sol-rune) + [Ith](../runes.md#ith-rune) in a 3-socket helm.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Nef Rune, Sol Rune, Ith Rune |
| Required level | 27 (the highest rune's) |
| Fits | Helm |

## Properties

- +75% Enhanced Defense
- +30 Defense vs. Missile
- +10 to Vitality
- +10 to Energy
- +33 to Mana
- Damage Reduced by 7
- Magic Damage Reduced by 3
- +15% Damage Taken Goes To Mana
- +5 to Light Radius

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
