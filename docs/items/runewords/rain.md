# Rain

[Ort](../runes.md#ort-rune) + [Mal](../runes.md#mal-rune) + [Ith](../runes.md#ith-rune) in a 3-socket armor.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Ort Rune, Mal Rune, Ith Rune |
| Required level | 49 (the highest rune's) |
| Fits | Armor |

## Properties

- 5% Chance to cast level 15 Twister on striking
- 5% Chance to cast level 15 Cyclone Armor when struck
- +2 to Druid Skill Levels
- +(100-150) to Mana
- Lightning Resist +30%
- Magic Damage Reduced by 7
- +15% Damage Taken Goes To Mana

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
