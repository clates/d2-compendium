# Treachery

[Shael](../runes.md#shael-rune) + [Thul](../runes.md#thul-rune) + [Lem](../runes.md#lem-rune) in a 3-socket armor.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Shael Rune, Thul Rune, Lem Rune |
| Required level | 43 (the highest rune's) |
| Fits | Armor |

## Properties

- 25% Chance to cast level 15 Venom on striking
- 5% Chance to cast level 15 Fade when struck
- +2 to Assassin Skill Levels
- +45% Increased Attack Speed
- +20% Faster Hit Recovery
- Cold Resist +30%
- 50% Extra Gold from Monsters

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
