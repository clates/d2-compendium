# Metamorphosis

[Io](../runes.md#io-rune) + [Cham](../runes.md#cham-rune) + [Fal](../runes.md#fal-rune) in a 3-socket helm.

|  |  |
| --- | --- |
| Sockets | 3 |
| Rune order | Io Rune, Cham Rune, Fal Rune |
| Required level | 67 (the highest rune's) |
| Fits | Helm |
| Ladder | seasons 3-14 |

## Properties

- Werewolf strikes grant Mark for 180 seconds
- Mark of the Wolf:
- 30% Bonus to Attack Rating
- Increase Maximum Life 40%
- Werebear strikes grant Mark for 180 seconds
- Mark of the Bear:
- +25% Attack Speed
- Physical Damage Received Reduced by 20%
- +5 to Shape Shifting Skills (Druid Only)
- +25% Chance of Crushing Blow
- +(50-80)% Enhanced Defense
- +10 to Strength
- +10 to Vitality
- All Resistances +10
- Cannot Be Frozen

The list includes the runes' own socket bonuses. The base must be a normal, superior or low-quality item (not magic, rare, set or unique) with exactly 3 empty sockets, and the runes go in in the order above. See [Sockets and runewords](../../mechanics/sockets-and-runewords.md).
